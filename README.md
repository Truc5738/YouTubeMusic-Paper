# YouTubeMusic-Paper

## 2.10.0 — Spotify-style UI
- UI Java 54 ô: tìm YouTube theo từ khóa, phát URL, hàng đợi, xóa từng mục/xóa toàn bộ.
- Thư viện cá nhân: ♥ yêu thích và 🕘 lịch sử, phát lại trực tiếp.
- Điều khiển: tạm dừng/tiếp tục, bỏ qua, dừng, lặp, trộn, radio, âm lượng.
- UI Bedrock/Floodgate: Forms tương ứng cho tìm kiếm, thư viện, hàng đợi và âm lượng.
- Tìm kiếm dùng YouTube Data API v3; audio vẫn dùng backend API-only, không có yt-dlp/ffmpeg.
- Lưu ý: Bedrock UI đã hoàn chỉnh về điều khiển nhưng đường phát audio hiện tại vẫn là Java resource-pack/custom-sound.
